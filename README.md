# MECHHAND

Cybernetic Chrome Jewellery & Kinetic Hand Articulations — Next.js 16 storefront featuring liquid-mirror alloy aesthetics, interactive cursor reveal shaders, and minimal Swiss typography.

## Overview

MECHHAND explores biological gestures, modular armor kinetics, and high-polish liquid chrome hardware.

- **Hero Experience:** Dual-layer video system with real-time multi-droplet liquid water reveal mask on cursor movement.
- **Floating iOS Liquid Glass Header:** Transparent frosted dark pill with custom 3D chrome iconography and minimal category navigation.
- **Product Architecture:** Hardware archive detailing technical specifications, metallurgical compositions, and stockist releases.
- **Styling:** Tailwind CSS v4, Helvetica typography, pure dark/cyan aesthetic with zero shadows.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) with your browser.

## Tech Stack

- **Framework:** Next.js 16 (Turbopack, App Router)
- **UI:** React 19, Tailwind CSS v4
- **Language:** TypeScript 5
